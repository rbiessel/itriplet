## Intensity Triplets for Closure Phase Inversions
A physically motivated framework for identifying and correcting closure phases related to soil moisture changes.

### Physical Basis
Via De Zan and Gomba (2018), an interferometric model for soil moisture can be simplified via
$$ \gamma(\Delta k) = \frac{1/2}{j(\Delta k + \alpha)} $$
where $\Delta k$ is the change in the real part of the permittivity and $\alpha \ne 0$ is a constant that describes the average imaginary part.

Backscatter intensity changes $\Delta \rho$ are also sensitive to changes to the real part of the permittivity $\Delta \rho = \beta \Delta k$.

We can combine this empirical backscatter intensity relationship with De Zan and Gombas model to yield an expression for the soil moisture phase:
$$ \phi(\Delta \rho) = \arctan(\lambda \rho),$$
where $\lambda = 1 / \alpha \beta$.

The expression for the soil moisture phase can then be extended to triplets of interferograms, or closure phases derived from linear combinations of more than three interferograms.
